# 跨平台基准测试片（Benchmark）

「装得上」不等于「拍得出」。这个 fork 用一支统一的测试片给每个 Harness / 模型组合定级，结果只认实测，记录在 `compat/results/`，并同步到 `UNIVERSAL.md` 的兼容矩阵。

## 测试片定义

| 项 | 规定 |
|---|---|
| 风格 | **蓝图 Blueprint**（纯 2D 线语言、无外部数据、无版权素材、确定性强，成败一眼可判） |
| 题目 | 「一台手摇发电的营地灯」——发明物，不涉及真实品牌/产品/数据，FACTS 压力为零，纯考导演与引擎执行 |
| 时长 | 20–30 秒，1920×1080，24fps |
| 旁白 | 中文，6–8 句，内容由 Agent 按 DIRECTOR.md 自拟（考它写 treatment 的能力） |
| 流程 | 必须走完整流程：一次提问 → TREATMENT.md → 风格帧 → 成片 → 按 DIRECTOR.md §11 自检交付。**分镜门强制开启**（storyboard 先审），因为弱模型最容易在不审稿时漂移 |
| 禁止 | 不许改 `styles/`、`core/` 讨过关；卡住时记录卡点，不许人工代写代码片段后宣称通过 |

## 验收表（逐项勾，缺一降级）

**流程纪律**
- [ ] 只问了一轮问题就开工，没有反复追问
- [ ] TREATMENT.md 在打开 DEMO.md / demo 代码之前写成
- [ ] 自检真实执行（readcheck / subcheck / asr_check 有实际输出，不是口头声称）

**风格不变量（抽开场、中段、结尾 3 帧查）**
- [ ] 全片蓝白两色，第三色（印章）只出现一次
- [ ] 成图顺序符合制图顺序：中心线 → 轮廓 → 细节 → 剖面线 → 尺寸 → 气泡编号
- [ ] 线宽随缩放变化（特写不粗成香肠、远景不消失）
- [ ] 字幕是图纸注释形态（NOTE 单元格），没压住标题栏与主体图
- [ ] 至少出现一次平面→斜投影/爆炸的原生动作

**技术交付**
- [ ] 输出 1920×1080 / 24fps / H.264，响度约 −14 LUFS
- [ ] 中文字幕单行不折行、停留时长达标；旁白与字幕逐句对得上（asr_check 通过）
- [ ] 项目文件夹完整：成片 + 源码 + FACTS/CREDITS（如适用）

## 定级

| 级 | 含义 |
|---|---|
| A | 全表通过，成片可直接交付 |
| B | 成片完成，风格不变量有 1–2 处小错，不影响理解 |
| C | 能出风格帧/分镜，成片未完成或质量明显漂移——该平台只推荐轻量用法 |
| F | 流程跑不通（装不上、依赖失败、长程任务中断） |

## 结果记录

每个组合一份 `compat/results/<harness>-<model>.md`：日期、版本、耗时、Token/费用（能拿到就记）、定级、3 帧截图、卡点原文。没跑过的组合在矩阵里写「待测」，不许写「支持」。
